Эмулятор советского растрового графического дисплея **«Электроника МС 7401»** (выпускался в Виннице, ЦКБИТ, по ТУ 11-БК0.305.055ТУ-84), предназначенный для запуска и визуализации старых графических Pascal-программ (например, `graf.pas`, `graf1.pas`) без реального железа.

Проект восстанавливает систему команд терминала по исходникам программ, поведению и статье:

> А. О. Лацис, Вс. С. Штаркман. **Системы команд растрового графического дисплея «Электроника МС7401»** // Микропроцессорные средства и системы. — 1989. — № 5. — С. 39–44.

## Установка

```bash
./install.sh                 # Linux/macOS, пользовательская установка
./install.sh --venv .venv    # в виртуальное окружение
```

```powershell
.\install.ps1               # Windows, окружение .\mc7401-env
```

Подробно, включая связь с БЭСМ-6: [`docs/DEPLOY.md`](docs/DEPLOY.md).
Справочник системы команд: [`docs/COMMANDS.md`](docs/COMMANDS.md).

## Короткие команды

```bash
source tools/mc7401-completion.bash      # bash
source tools/mc7401.fish                 # fish
```

| Команда | Что делает |
|---|---|
| `mc <файл> …` | отрисовать поток команд |
| `мск <файл> …` | то же кириллицей |
| `мсг <сценарий>` | сгенерировать эталонный кадр |
| `мсд <файл>` | показать кадр текстом (ASCII-арт) |
| `мсдк [хост:порты]` | подключиться к БЭСМ-6 по ДКС |
| `мсв [хост:порт]` | слушать порт ДКС |

## Возможности

- **Парсинг** потока команд терминала из бинарного файла, pipe или stdin.
- **Три backend'а рендеринга**:
  - `svg` — статические изображения (для документации и отладки);
  - `tk` — интерактивный просмотр в окне;
  - `pygame` — анимации и XOR-режим (для `КИНО`, `ПТИЦА`, `ЧАСЫ`).
- **Полная эмуляция** системы команд: рисование линий, окружностей, прямоугольников, текста, режимы OR/XOR/erase, отсечение по окну.
- **Поддержка КОИ-8** и переключения русский/латинский шрифт (спецкоды `S0`/`S1`).
- **Смещение окна** (команда `}`) — накопление и учёт при рендеринге.
- **Типы линий** `0..7` (сплошная, штриховая, пунктир, штрих-пунктир и т. д.).
- **Экспорт** в PNG (собственный кодировщик, без внешних зависимостей) и SVG.
- **CLI** на `argparse` с выбором backend'а, входного файла, выходного файла.

## Аппаратные характеристики

Восстановлены из статьи МПСС 5/1989 и исходников `graf.pas`:

| Параметр | Значение |
|---|---|
| Разрешение экрана | **560 × 400** точек |
| Формат видеопамяти | **7 точек на 1 байт** |
| Объём видеопамяти | **~32 Кбайт** |
| АЦ-режим | Совместим с **DEC VT-52** (7-битная кодировка) |
| Префикс графической команды | **ESC F** (`’≡124’` + `’F‾’`) |
| Разделитель команд | **ВК** = `’≡125’` (octal 125 = 85) |
| Разделитель параметров | **П1** = пробел |
| Маркер конца текста | **ЕND** = `’≡377’` |
| Переключение шрифта | `S0 = ’≡160’` (рус.), `S1 = ’≡161’` (лат.) |
| Перья | рисующее (`+`, OR), инвертирующее (`≠`, XOR), стирающее |
| Отсечение | по краю экрана или окну; отключить нельзя |
| Типы линий | `0..7` (тип `6` отключён) |

**Процессор встроенной ЭВМ дисплея:** К1801ВМ1 (аналог PDP-11).

## Система команд

Краткая таблица; полный справочник с протоколом ВУК, шрифтами и
пользовательскими знаками — [`docs/COMMANDS.md`](docs/COMMANDS.md).

Записи разделены `ВК` (0o125 = 85 = `'U'`), параметры — через пробел.
Координаты: `X` вправо, `Y` вверх, начало в левом нижнем углу,
экран 560×400.

| Команда | Формат | Назначение |
|---|---|---|
| `J0` | `J0 ВК` | Текстовый режим |
| `J1` | `J1 ВК` | Графический режим |
| `S` | `S ВК` | Очистка экрана |
| `K` | `K ВК` | Сброс состояния |
| `4` | `4 X Y ВК` | Абсолютное перемещение |
| `5` | `5 dX dY ВК` | Относительное перемещение |
| `7` | `7 T X Y ВК` | Линия к абсолютной точке |
| `8` | `8 T dX dY ВК` | Линия относительно точки |
| `]` | `] X1 Y1 X2 Y2 ВК` | Прямоугольник |
| `>` | `> T R ВК` | Окружность радиуса `R` |
| `}` | `} X Y ВК` | Смещение окна |
| `0` | `0 C ВК` | Установка пера |
| `1` | `1 C ВК` | Установка типа линии |
| `*` | `* C ВК` | Стирание пером `C` |
| `+` | `+ ВК` | Режим OR (рисование) |
| `≠` | `≠ ВК` | Режим XOR (инверсия) |
| `9` | `9 S ВК`, `;O П1 текст ВК` | Текст |
| `9:` | `9 S ВК`, `:N ВК` | Установка размера текста |
| `3` | `3 ВК` | Конец обновления экрана |

**Спецкоды:** `S0` (0o160, русский шрифт), `S1` (0o161, латинский),
`END` (0o377, конец текста), `LF` (0o175, смещение окна),
`АР2` (0o124, префикс маркеров кадра), `0o32` (заполнитель кадра).

**Кадрирование ВУК:** `'/' ВК 'z' + 19 нулей <данные> АР2 'F‾' ВК`,
порог 192 байта.
