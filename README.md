Эмулятор советского растрового графического дисплея **«Электроника МС 7401»** (выпускался в Виннице, ЦКБИТ, по ТУ 11-БК0.305.055ТУ-84), предназначенный для запуска и визуализации старых графических Pascal-программ (например, `graf.pas`, `graf1.pas`) без реального железа.

Проект восстанавливает систему команд терминала по исходникам программ, поведению и статье:

> А. О. Лацис, Вс. С. Штаркман. **Системы команд растрового графического дисплея «Электроника МС7401»** // Микропроцессорные средства и системы. — 1989. — № 5. — С. 39–44.

## Установка

```bash
./install.sh                 # Linux/macOS, пользовательская установка
./install.sh --venv .venv    # в виртуальное окружение
```

```powershell
.\install.ps1               # Windows, окружение .\mc7401-env
```

Подробно, включая связь с БЭСМ-6: [`docs/DEPLOY.md`](docs/DEPLOY.md).
Справочник системы команд: [`docs/COMMANDS.md`](docs/COMMANDS.md).

## Короткие команды

```bash
source tools/mc7401-completion.bash      # bash
source tools/mc7401.fish                 # fish
```

| Команда | Что делает |
|---|---|
| `mc <файл> …` | отрисовать поток команд |
| `мск <файл> …` | то же кириллицей |
| `мсг <сценарий>` | сгенерировать эталонный кадр |
| `мсд <файл>` | показать кадр текстом (ASCII-арт) |
| `мсдк [хост:порты]` | подключиться к БЭСМ-6 по ДКС (графическое окно) |
| `мсв [хост:порт]` | слушать порт ДКС |

Без аргументов и при подключении к линии открывается **графическое
окно** терминала; `--tui` выбирает текстовый интерфейс в консоли.

## Возможности

- **Парсинг** потока команд терминала из бинарного файла, pipe или stdin.
- **Три backend'а рендеринга**:
  - `svg` — статические изображения (для документации и отладки);
  - `tk` — интерактивный просмотр в окне;
  - `pygame` — анимации и XOR-режим (для `КИНО`, `ПТИЦА`, `ЧАСЫ`).
- **Полная эмуляция** системы команд: рисование линий, окружностей, прямоугольников, текста, режимы OR/XOR/erase, отсечение по окну.
- **Единый графический экран**: текст выводится графическими символами из эталона СИМ — растром ПЗУ 7×8 без увеличения, знакомест 8×10, сетка **70×40 знакомёстов** на кадре 560×400. Текстовые данные из БЭСМ-6 преобразуются в них и рисуются в позиции курсора. Размер растра на кадре задаётся `[terminal] glyph`, размер на экране — размером окна.
- **Все знаки — одной метрики**: латиница и кириллица взяты из одного дампа ПЗУ КР556РТ5, прописные занимают 8 точек, строчные 7 — набора знаков из двух разных шрифтов на экране нет.
- **Ввод на любую строку экрана**: курсор (стрелки или мышь) в любом знакомёсте, набранные знаки рисуются там же глифами СИМ и уходят на ЭВМ.
- **Режимы АВТОНОМНО / С ЭВМ** (клавиша F9 «СЕТЬ»): набор в буфер с отправкой по ПЕРЕДАЧА или немедленно в линию.
- **Мышь как на 15ИЭ**: левая кнопка — курсор в знакомёст или штрих светового пера (F2 «ПЕРО»), правая и средняя — стирание, колесо листает историю выдачи (F5 «ОЧИСТКА» складывает кадры в историю).
- **Кадр равен размеру окна**: строка состояния прижата к **верху** окна, подвал — к **низу**, кадр занимает всё между ними и прижат к левому краю. Окно по умолчанию разворачивается на весь экран, но его можно растягивать — кадр вписывается заново при каждом изменении размера. Масштаб дробный (Tk 8.6 не умеет целый `zoom`, поэтому кадр растягивается по сериям точек), и знак ПЗУ на экране меняет размер вместе с окном.
- **Служебные строки — глифами ПЗУ**: строка состояния стоит **над** кадром, как на 15ИЭ, подвал — **под** ним и привязан к нижней границе экрана. Подвал не наезжает на рабочее поле: текст ОС виден целиком. Обе строки рисуются тем же знаком, что и текст в кадре; структура подвала — как на 15ИЭ-00-013 (ячейки «метка=значение» в ровных колонках, черта, легенда клавиш), разложена в три колонки по 9 знакомест.
- **Поддержка КОИ-8** и переключения русский/латинский шрифт (спецкоды `S0`/`S1`).
- **Смещение окна** (команда `}`) — накопление и учёт при рендеринге.
- **Типы линий** `0..7` (сплошная, штриховая, пунктир, штрих-пунктир и т. д.).
- **Экспорт** в PNG (собственный кодировщик, без внешних зависимостей) и SVG.
- **CLI** на `argparse` с выбором backend'а, входного файла, выходного файла.

## Аппаратные характеристики

Восстановлены из статьи МПСС 5/1989 и исходников `graf.pas`:

| Параметр | Значение |
|---|---|
| Разрешение экрана | **560 × 400** точек |
| Формат видеопамяти | **7 точек на 1 байт** |
| Объём видеопамяти | **~32 Кбайт** |
| АЦ-режим | Совместим с **DEC VT-52** (7-битная кодировка) |
| Префикс графической команды | **ESC F** (`’≡124’` + `’F‾’`) |
| Разделитель команд | **ВК** = `’≡125’` (octal 125 = 85) |
| Разделитель параметров | **П1** = пробел |
| Маркер конца текста | **ЕND** = `’≡377’` |
| Переключение шрифта | `S0 = ’≡160’` (рус.), `S1 = ’≡161’` (лат.) |
| Перья | рисующее (`+`, OR), инвертирующее (`≠`, XOR), стирающее |
| Отсечение | по краю экрана или окну; отключить нельзя |
| Типы линий | `0..7` (тип `6` отключён) |

**Процессор встроенной ЭВМ дисплея:** К1801ВМ1 (аналог PDP-11).

## Клавиши окна терминала

Раскладка — как на 15ИЭ-00-013: служебные действия висят на
**функциональных** клавишах, буквы свободны (иначе текст не набрать).

| Клавиша | Действие |
|---|---|
| `F2` | **ПЕРО** — мышь рисует по кадру (световое перо) |
| `F3` | **ИНСТРУМЕНТ** пера: штрих → точка → стирание → инверсия |
| `F5` | **ОЧИСТКА** — экран очищается, прежний кадр уходит в историю |
| `F6` | **ЭХО** — вкл/выкл вывод набора (для паролей) |
| `F8` | **НАБОР** — Н2 (КОИ-7) ↔ КОИ-8Р |
| `F9` | **СЕТЬ** — АВТОНОМНО ↔ С ЭВМ |
| `F10` | **ПЕРЕДАЧА** — отдать накопленное на ЭВМ |
| `F12` | **ВЫХОД** — закрыть терминал (работает и `Ctrl-q`) |
| левая мышь | курсор в знакомёст; с включённым пером — штрих |
| правая / средняя мышь | стирающее перо |
| колесо мыши | листать историю выдачи (то же, что PgUp/PgDn) |
| `ВК` / `ПРПС` / `ESC` | стереть знак / конец строки / сброс набора |
| `Ctrl-c` / `Ctrl-q` | курсор в центр кадра, выход |

Курсор в окне мигает, а при работе (набор, стрелки, вывод ЭВМ) горит
ровно — погасший курсор посреди набора читается как «клавиатура не
работает».

### Настройки (`mc7401 --init-config`)

| Параметр | Значение |
|---|---|
| `[terminal] glyph` | увеличение растра ПЗУ на кадре: `1` — без увеличения, знакомест 8×10, сетка 70×40 (**по умолчанию**), `2` — знакомест 16×20, сетка 35×20, `3`…`4` — ещё крупнее. Служебные строки окна выводятся тем же знаком и растут вместе с текстом |
| `[terminal] help` | `false` — убрать из подвала ряды-легенды клавиш (как `--no-help` на 15ИЭ) |
| `[terminal] pen` | стартовать со включённым световым пером |
| `[display] fullscreen` | `false` — открыть окно обычным размером, растягиваемым мышью |
| `[display] scale` | ограничение увеличения кадра: `0` — кадр ровно по размеру окна (**по умолчанию**), положительное число запрещает кадру стать крупнее |
| `[line] endpoint` | линии ДКС: `4202`, `4202,4210`, `4202-4223` |

## Система команд

Краткая таблица; полный справочник с протоколом ВУК, шрифтами и
пользовательскими знаками — [`docs/COMMANDS.md`](docs/COMMANDS.md).

Записи разделены `ВК` (0o125 = 85 = `'U'`), параметры — через пробел.
Координаты: `X` вправо, `Y` вверх, начало в левом нижнем углу,
экран 560×400.

| Команда | Формат | Назначение |
|---|---|---|
| `J0` | `J0 ВК` | Упразднён: принимается и игнорируется |
| `J1` | `J1 ВК` | Графический режим |
| `S` | `S ВК` | Очистка экрана |
| `K` | `K ВК` | Сброс состояния |
| `4` | `4 X Y ВК` | Абсолютное перемещение |
| `5` | `5 dX dY ВК` | Относительное перемещение |
| `7` | `7 T X Y ВК` | Линия к абсолютной точке |
| `8` | `8 T dX dY ВК` | Линия относительно точки |
| `]` | `] X1 Y1 X2 Y2 ВК` | Прямоугольник |
| `>` | `> T R ВК` | Окружность радиуса `R` |
| `}` | `} X Y ВК` | Смещение окна |
| `0` | `0 C ВК` | Установка пера |
| `1` | `1 C ВК` | Установка типа линии |
| `*` | `* C ВК` | Стирание пером `C` |
| `+` | `+ ВК` | Режим OR (рисование) |
| `≠` | `≠ ВК` | Режим XOR (инверсия) |
| `9` | `9 S ВК`, `;O П1 текст ВК` | Текст |
| `9:` | `9 S ВК`, `:N ВК` | Установка размера текста |
| `3` | `3 ВК` | Конец обновления экрана |

**Спецкоды:** `S0` (0o160, русский шрифт), `S1` (0o161, латинский),
`END` (0o377, конец текста), `LF` (0o175, смещение окна),
`АР2` (0o124, префикс маркеров кадра), `0o32` (заполнитель кадра).

**Кадрирование ВУК:** `'/' ВК 'z' + 19 нулей <данные> АР2 'F‾' ВК`,
порог 192 байта.
