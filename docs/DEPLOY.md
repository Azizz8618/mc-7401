# Развёртывание и связь с БЭСМ-6

Документ описывает установку эмулятора МС 7401 на Linux/macOS и
Windows, короткие команды оболочки и проверку связи с БЭСМ-6 по
каналу ДКС.

---

## 1. Требования

| Что | Версия | Обязательно |
|---|---|---|
| Python | 3.10 или новее | да |
| Ядро эмулятора | только стандартная библиотека | — |
| pygame | любой | нет, просмотр анимации |
| tkinter | из поставки Python | нет, интерактивный просмотр |

Проверить: `python3 -V`

---

## 2. Установка

### Linux / macOS

```bash
git clone <репозиторий> mc7401 && cd mc7401

./install.sh                 # пользовательская установка в ~/.local
./install.sh --venv .venv    # в виртуальное окружение
./install.sh --system        # системно (нужен sudo)
./install.sh --dev           # редактируемая установка + pytest и ruff
./install.sh --gui           # с pygame и tkinter
./install.sh --uninstall     # удалить
```

Скрипт сам проверяет версию Python, собирает пакет и выполняет
контрольный запуск `mc7401 --version`.

Если после установки скрипты не находятся:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

### Windows

```powershell
git clone <репозиторий> mc7401
cd mc7401

.\install.ps1            # окружение .\mc7401-env, установка в него
.\install.ps1 -Dev       # плюс pytest и ruff
```

Скрипт создаёт виртуальное окружение, чтобы не трогать системный
Python, и сам находит подходящий интерпретатор (`py -3`, `python`,
`python3`). Запуск:

```powershell
.\mc7401-env\Scripts\mc7401.exe поток.bin -o кадр.png
```

Чтобы не набирать полный путь:

```powershell
$env:PATH += ";$PWD\mc7401-env\Scripts"
```

### Без установки

Работает прямо из исходников, ничего ставить не нужно:

```bash
python3 -m mc7401 golden/streams/СЕТ.bin -o кадр.png
python3 -m pytest tests/ -q
```

## 3. Короткие команды

### bash

```bash
source tools/mc7401-completion.bash
```

Чтобы команды действовали всегда, добавьте строку в `~/.bashrc`:

```bash
source /путь/к/mc-7401/tools/mc7401-completion.bash
```

| Команда | Что делает |
|---|---|
| `mc <файл> …` | отрисовать поток (короткая форма `mc7401`) |
| `мск <файл> …` | то же кириллицей |
| `мсг <сценарий>` | сгенерировать эталонный кадр |
| `мсд <файл>` | показать кадр текстом (ASCII-арт) |
| `мсдк [хост:порты]` | подключиться к БЭСМ-6 по ДКС |
| `мсв [хост:порт]` | слушать порт ДКС |

Автодополнение работает для всех шести команд: имена сценариев
берутся из `tools/gen_golden.py`, поэтому список не расходится с кодом.

```bash
$ мсг <TAB>          → СЕТ  СОЛ  КОТ  ЦЕП  ФУН  ЗАГ …
$ мсг СЕТ            → СЕТ:  2994 Б в линию, 280 команд, 60233 точек …
```

### fish

```bash
source tools/mc7401.fish
```

Постоянно — положить в `~/.config/fish/conf.d/mc7401.fish`.
Команды те же, автодополнение описывает ключи, файлы и сценарии.

## 4. Связь с БЭСМ-6 по ДКС

### Кто слушает порт

**ЭВМ слушает порт, терминал к нему подключается.** В SIMH линии
telnet работают как мультиплексор (`TMXR tty_desc` в
`BESM6/besm6_tty.c`), а режим ДКС включается командой
`set ttyN dks,raw` (`tty_set_dks`). Типовая конфигурация:

```
; tty3..tty24 занимают порты 4202..4223
set dks enabled
attach tty3 Line=3,4202
set tty3 dks,raw
```

Это подтверждает и наш модуль `mc7401/link.py`, где роли обратные
ситуации `ie15/ie15emu/link.py`.

### Направление данных

| Направление | Что передаётся |
|---|---|
| ЭВМ → терминал | байты потока команд графики МС 7401 |
| терминал → ЭВМ | ввод с клавиатуры; локальное эхо и редактирование строки делает сама линия ДКС |

Между сессиями SIMH печатает `DKS: line busy` или
`DKS: no free terminal`; такой порт при переборе пропускается.

### Проверка

```bash
python3 tools/check_dks_link.py
python3 tools/check_dks_link.py --ports 4203 --seconds 30 --render кадр.png
```

Скрипт опрашивает порты, подключается к первой свободной линии,
принимает данные, разбирает поток и печатает отчёт. Коды возврата:
`0` — данные получены, `1` — линия поднялась, но данных не было,
`2` — ни один порт не ответил.

### Руками

```bash
mc --link 127.0.0.1:4202 --png кадр.png    # подключиться к ЭВМ
mc --listen 127.0.0.1:4202                 # обратный режим: слушать
мсдк 127.0.0.1:4202                        # то же короткой командой
```

### Что проверено

Прогон против `simh/BESM6` с ОС Диспак (`scripts/test_dks.sh`):

* порт 4202 занят — SIMH ответил `line busy`, клиент перешёл на 4203
  (логика отсева работает на живом стенде);
* telnet-приветствие («`Encoding is RAW`, `WRU …`, `Connected to DKS`»)
  приходит без IAC-последовательностей — срезка работает;
* после подключения приходит приглашение ОС Диспак `ЭВМ-3`;
* отправленный с терминала `ETX` (0x03) возвращается эхом — работает
  локальное эхо ДКС, то есть линия двусторонняя.

**Ограничение.** Эта линия ДКС ведёт текстовую сессию ОС Диспак
(приглашение `ЭВМ-3`), а не поток графики МС 7401. Сам МС 7401 —
модуль вывода микроконтроллера семейства МИДИКОН, работающего на
стороне Электроники-60; на БЭСМ-6 он не подключён. Графику МС 7401
получают офлайн: `tools/gen_golden.py` воспроизводит поток команд из
`golden/graf.pas`, а `mc7401` его отображает.
